# Brokerage Rate Management System

## Project Overview

The Brokerage Rate Management System is a database project designed to manage brokers, customers, insurance products, brokerage rates, policies, and brokerage transactions.

## Technologies

- Oracle SQL
- PL/SQL
- Relational Database Management System (RDBMS)

## Key Features

- Broker management
- Customer management
- Insurance product management
- Brokerage rate management
- Policy management
- Brokerage calculation
- Brokerage rate history
- SQL reports
